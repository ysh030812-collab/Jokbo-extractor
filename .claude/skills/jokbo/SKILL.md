# 족보 문제 추출

강의안을 읽고, 그 내용만으로 풀 수 있는 기출문제를 족보에서 골라 PDF로 묶는다.
**판정은 네가 직접 한다.** 스크립트는 후보를 추리고 PDF를 만드는 기계적 작업만 맡는다.

## 준비 확인

작업 폴더는 이 저장소 루트다. 다음이 있어야 한다.

- `자료/` — 족보 파일. 이름 규칙: `{연도} {과목} {중간기말} 풀이.pdf`, `{연도} {과목} {중간기말}.docx`
- `bank.json` — 문제 은행. 없거나 `자료/`보다 오래됐으면 먼저 만든다.

```bash
python jokbo.py index
```

`index` 는 각 시험에서 몇 문제를 뽑았는지 출력한다. **0문제거나 눈에 띄게 적으면 거기서 멈추고 사용자에게 알린다** — 파일 이름 규칙이 어긋났거나 풀이 PDF 구조가 예상과 다른 것이다. 그대로 진행하면 "관련 문제 없음"이라는 잘못된 결론이 나온다.

## 절차

### 1. 후보 추리기

```bash
python jokbo.py search "<강의안.pdf>" --subject 감면 --top 60
```

BM25로 어휘가 겹치는 상위 N개를 JSON으로 돌려준다. 이건 **사전 필터일 뿐 판정이 아니다.** 점수가 높다고 풀 수 있는 문제가 아니고, 낮다고 무관한 것도 아니다.

문제 은행이 작으면(200문제 이하) `--top` 을 넉넉히 주거나 `bank.json` 을 통째로 읽어도 된다.

### 2. 강의안 읽기

`Read` 로 강의안 PDF를 직접 읽는다. PDF는 네이티브로 처리되므로 **그림·표·도표까지 그대로 볼 수 있다.** 별도 OCR이 필요 없다.

분량이 많으면 `pages` 로 나눠 읽는다. 페이지 번호를 기억해 둔다 — 판정 근거로 쓴다.

### 3. 판정

후보마다 판단한다. 기준은 **"이 강의안 내용만으로 풀 수 있는가"** 이지, 단어가 겹치는가가 아니다.

| 등급 | 뜻 |
|---|---|
| `solvable` | 강의안에 답을 고를 근거가 다 있다 |
| `partial` | 개념은 있으나 문제가 요구하는 세부(약제명, 수치, 예외)가 강의안에 없다 |
| `unrelated` | 무관하거나, 다른 강의 범위다 |

- **`partial` 을 적극적으로 쓴다.** 억지로 둘로 가르면 정확도가 떨어진다. 애매한 건 사용자가 판단하게 둔다.
- 근거가 된 **강의안 페이지 번호**를 반드시 남긴다. 이게 있어야 사용자가 검증할 수 있다.
- 족보 해설에 "강의록 ○○ page" 참조가 있으면 강한 단서다. 다만 그 참조가 **지금 이 강의안**을 가리키는지 확인한다 — 다른 교수님 강의록일 수 있다.
- "복원실패" 처럼 본문이 없는 문제는 `unrelated` 로 두고 이유를 적는다.

### 4. 확인받기

표로 보여주고 사용자가 가감하게 한다. 기본 선택은 `solvable` 만.

```
포함  연도    번호   등급        근거           요약
 ✅   2023 기말 48   solvable    강의안 12쪽    인플루엔자 항원변이
 ✅   2026 기말  3   solvable    강의안 15,16쪽 항진균제 작용기전
 ⬜   2022 기말 31   partial     강의안 9쪽     개념만 있고 용량은 없음
```

**사용자 확인 없이 5단계로 넘어가지 않는다.**

### 5. PDF 만들기

```bash
python jokbo.py build --subject 감면 --out 12.pdf \
  --select '[{"year":2023,"term":"기말","q":[48]},{"year":2026,"term":"기말","q":[3]}]'
```

연도 최신순 → 같은 연도는 기말→중간 → 문제번호 순으로 정렬되고, 구간마다 표지가 붙는다.
완성되면 `SendUserFile` 로 사용자에게 바로 보낸다.

경고가 나오면 그대로 전달한다. 특히 `풀이 PDF와 시험 DOCX 어디에서도 찾지 못함` 은 문제 은행과 실제 파일이 어긋났다는 뜻이므로 삼키지 말 것.

## 커버리지 리포트

"이 강의안에서 안 나온 부분"을 물으면, 3단계 판정 결과를 뒤집어 답한다. 강의안의 어느 주제가 `solvable` 후보를 하나도 갖지 못했는지 짚어 준다. 추가 실행은 필요 없다.

## 하지 말 것

- **문제를 지어내지 않는다.** 이 스킬은 기존 족보에서 고르는 것이다. 새 문제가 필요하면 사용자에게 먼저 확인하고, 만들면 반드시 "AI 생성" 표시와 근거 페이지를 붙인다.
- **점수만 보고 자동 선택하지 않는다.** BM25 점수는 순서를 정할 뿐이다.
- **`자료/` 안의 파일을 수정하거나 지우지 않는다.** 원본이다.
